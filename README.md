# Рапорт прораба — ГК «КРАШМАШ»

Шаблон сменного рапорта прораба.

- Конструктор и форма прораба: `index.html` (форма открывается по персональной ссылке, настройки объекта зашиты в ссылку).
- Кабинет руководителя: `director.html` (открывается по ссылке с ключом).
- Папка `o/` — зашифрованные паспорта объектов; прочитать их можно только по ссылке прораба.
- Исходники — `src/`, сборка `python3 src/build.py`.
